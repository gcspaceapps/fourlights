# 04_submit: every field in, on time

One job: submit the project, every Submission Guide field complete, before our deadline.

## Inputs
Working (this run): `../03_pitch/output/project-page.md`, `../03_pitch/output/pitch.md`, the live demo URL.
Reference (every run): `../../_shared/rules.md`, `../../_shared/judging.md`.
Do NOT load: code folders, `data/`, `stages/01_data/`.

## Process
1. **Sunday ~19:30 AEST: make the repo public**: `gh repo edit gcspaceapps/fourlights --visibility public --accept-visibility-change-consequences` (and the demo/deck link), before the link checks.
2. Move the demo to our own domain if planned, then check the README runs cold.
3. Open every link in a private browser window: the demo, the video or deck, the repo, every dataset link.
4. Fill each field on the Space Apps project page from `../03_pitch/output/project-page.md`; tick it off in `output/submission.md`.
5. **Submit by 22:00 Sun 15 Nov AEST** (our internal deadline; the official close is 11:59pm Sun 15 Nov, Queensland time). Record the URL and the time.
6. If the site is down: screenshot the error with the time, tell the organisers, keep retrying.

## Outputs
`output/submission.md`: every field with its status, the submitted URL and time.

## Human check
The person who didn't submit opens the submitted page in a private window and checks the demo, video or deck and every link.
