# Datasets

Every dataset used has a card here and a line in the README credits before it ships. Status: verified → loaded → used.

| Card | What | Status |
|---|---|---|
| [nasa-lola-topography](nasa-lola-topography.md) | LOLA south-pole elevation models (5 m to 240 m) for the terrain horizons | loaded |
| [nasa-jpl-horizons](nasa-jpl-horizons.md) | Sun and Earth azimuth/elevation from each lunar site (Horizons API; SPICE fallback) | loaded |
| [nasa-naif-spice](nasa-naif-spice.md) | SPICE kernels: DE440s, Moon ME frame, DSN station positions (fallback ephemeris, Canberra Link) | loaded |
| [usgs-artemis-regions](usgs-artemis-regions.md) | USGS navigational grids for the Artemis candidate regions (site centres) | loaded |
| [nasa-image-library](nasa-image-library.md) | Three NASA photographs (Surveyor 3, a VIPER prototype, the Apollo 11 lunar module) as examples of the power-system classes | used |
| [ours-moon-imaging](ours-moon-imaging.md) | Optional: our own timestamped image of the Moon's south limb, Sat 14 Nov evening | candidate |
